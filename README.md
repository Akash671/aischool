# 🤖 aischool

Welcome to **aischool**—a comprehensive, self-paced learning path designed to take you from foundational mathematics to deploying advanced Generative AI and Reinforcement Learning agents safely.

## 🗺️ Curriculum Overview

### 📊 1. Data Science Foundations
* Exploratory Data Analysis (EDA) & Visualization
* Statistical Inference & Data Preprocessing
* Feature Engineering & Model Evaluation

### 🤖 2. Machine Learning & Deep Learning
* Classical ML: Regression, Trees, and Ensemble Methods
* Neural Network Architectures (CNNs, RNNs)
* Optimization, Loss Functions, and Regularization

### 🗣️ 3. Natural Language Processing (NLP)
* Text Processing, Tokenization, and Embeddings (Word2Vec)
* Sequence-to-Sequence Models & Attention Mechanisms
* Custom Transformer Architectures from Scratch

### 🌌 4. Generative AI (GenAI)
* Prompt Engineering & In-Context Learning
* Fine-Tuning Large Language Models (LLMs) via LoRA/PEFT
* Retrieval-Augmented Generation (RAG) Architectures

### 🎮 5. Reinforcement Learning (RL)
* Markov Decision Processes & Q-Learning
* Deep Q-Networks (DQN) & Policy Gradient Methods
* Building and Training Custom RL Environments

### 🛡️ 6. Data Security in AI (DataSec)
* Privacy-Preserving Machine Learning & Differential Privacy
* Securing LLM Pipelines (Mitigating Prompt Injection & Data Leakage)
* Adversarial Robustness and Model Auditing
